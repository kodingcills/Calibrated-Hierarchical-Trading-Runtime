## Question being answered

How does execution-aware expected value decay as a function of decision-to-market delay for this signal?

## Why public evidence cannot answer it

No public source supplies a venue-specific EV(delay) curve for these signals; the literature reports next-tick predictability only.

## Dataset required

Causal replay dataset for the candidate's venue with order-level events and the project timestamp contract.

## Primary metric

Execution-aware EV in bps by delay bucket

## Null hypothesis

Delay-shuffled control: same signal values assigned to randomly shifted timestamps within the same regime block.

## Baselines

zero-delay gross markout; deterministic imbalance/microprice formula without any learned model

## Kill criterion
