- Kill rule: do not run a pilot if any required source is unavailable, if timestamps cannot be paired within 5 seconds, if any expected funding hour is absent/duplicated, if any candle/book sample is stale or falls back to last trade, if archive completeness cannot be established, or if any required leg cost is unknown.
