# Bounded edge-discovery campaign

Question: Which structurally distinct trading-edge families deserve the next scarce verification budget, while preserving ES as an incumbent branch rather than the only branch?

Subquestions:
1. What does the incumbent ES branch still uniquely offer, and what is its cheapest falsifier?
2. Which forced-flow mechanisms have observable, economically distinct payer constraints?
3. Which relative-value families can survive convergence, legging, hedge, and fee costs?
4. Which market-design quirks create venue-specific, rule-conditioned edges rather than generic top-of-book repetition?
5. Where can horizon mismatch or capacity constraints leave a tractable niche?
6. Which search-process assumptions are likely to create false positives or selection bias?
7. Which cheap precursor measurements can kill or prioritize branches before external data spend?

Done when: seven independent groups have produced candidate findings with explicit evidence, falsifiers, cost/permission prerequisites, and confidence; material findings have been independently verified; weak branches are killed or deferred; only verified discoveries are cross-pollinated; a second-round allocation is derived from verification results rather than predefined; ES remains represented; and all decisions are persisted under .research/.
